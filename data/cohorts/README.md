# Cohort snapshots (public data)

Curated subset of **5 cancer cohorts** for the dual-mode somatic interpretation
demo. Generated by [`scripts/fetch_cohort.py`](../../scripts/fetch_cohort.py)
via the **cBioPortal REST API** (`https://www.cbioportal.org/api`) — no login,
no key. ~7 samples per cancer, restricted to a curated driver-gene panel.

| File | Cancer | Source study |
|---|---|---|
| `luad_tcga_pan_can_atlas_2018.json` | NSCLC (lung adeno) | TCGA PanCancer Atlas |
| `brca_tcga_pan_can_atlas_2018.json` | Breast | TCGA PanCancer Atlas |
| `coadread_tcga_pan_can_atlas_2018.json` | Colorectal | TCGA PanCancer Atlas |
| `skcm_tcga_pan_can_atlas_2018.json` | Melanoma | TCGA PanCancer Atlas |
| `paad_tcga_pan_can_atlas_2018.json` | Pancreatic | TCGA PanCancer Atlas |

`cohort_manifest.json` records the fetch timestamp, gene panel, and selected
samples (provenance).

Selection guarantees **BRAF V600E in both melanoma and colorectal** (same
variant, different actionability tier — the headline dual-mode contrast).

**Attribution.** Data derived from The Cancer Genome Atlas (TCGA) via cBioPortal.
Please cite TCGA and cBioPortal (Cerami et al. 2012; Gao et al. 2013) in any
derived work. Open-access tier; research/education use only — not clinical.

Re-generate: `python -m scripts.fetch_cohort`
