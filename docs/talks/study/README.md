# 스터디 자료 — 논문 작업을 위한 Agent / Skill 운영

논문(프리프린트) 작성을 Claude Code의 **agent · skill · memory**로 분업·검증·학습시키는 방법을 소개하는 스터디용 자료 모음입니다. 실제 사례는 이 저장소의 **체세포 변이 해석 프리프린트**를 작성·검토한 세션 기록입니다.

> 본 프로젝트는 연구·교육·데모용입니다(임상용 아님). 도구는 *초안·검증·일관성*을 돕고, 과학적 판단의 최종 책임은 사람에게 있습니다.
