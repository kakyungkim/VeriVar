## 1. 식약처 LLM 기반 디지털의료기기 허가·심사 가이드라인 (핵심 문서)

- 등록번호 **안내서-1511-01**, 승인 **2026. 6. 30.**, 발간 의료기기심사부 의료인공지능소프트웨어과
- 법적 효력 없는 민원인 안내서다. 본문이 '~하여야 한다'로 쓰였어도 참고용이라고 문서 스스로 밝힌다.
- **선행 문서가 있다.** 2025년 1월 '생성형 인공지능 의료기기 허가·심사 가이드라인'이 이미 나왔고, 이번 안내서는 그 위에 LLM 특화 내용을 얹은 것이다. 해설글의 "세계 최초"는 이 계보를 감안해 읽어야 한다.
- 목차: Ⅰ 개요 → Ⅱ 해당 여부 예시 → Ⅲ 허가·심사 방안(신청서 작성, 분석적·임상적 유효성, 주요 기능 성능검증, 중요한 변경) → Ⅳ 참고문헌
- 적용 범위: 독자 파운데이션 모델과 상용 LLM 응용 둘 다. **외부 상용 모델 자체는 직접 관리 대상이 아니고**, 그것으로 구성한 의료용 응용 수준의 안전성·유효성만 다룬다. 사용적합성과 사이버보안은 별도 가이드라인 소관이고, 악의적 프롬프트 인젝션은 명시적으로 제외한다.
- LMM(다중 모달)은 직접 고려해 만들지 않았으나 유사한 범위에서 준용할 수 있다고 밝힌다.

### 7가지 위해요인과 검증 지표 (표7) — VeriVar와 직접 대응

| # | 위해요인 | 가이드라인이 제시한 검증 지표 | VeriVar 대응 |
|---|---|---|---|
| 1 | 정보 생성 오류(환각) | 원문·근거 대비 사실 일치율, **RAG 근거 일치성**, **근거 없는 주장 발생 비율** | hallucinated-citation rate 0.0, citation grounding 1.0 |
| 2 | 중요한 정보의 누락·왜곡 | 핵심 소견 재현율·민감도, 오류 검출 비율, 용어·날짜 오류율 | abstention recall 1.0, directional faithfulness 1.0 |
| 3 | 입력 맥락 오인식 | 임상 약어·은어 표준용어 매핑 정확도, 시간 순서 오인식률 | **미측정** (유전자 별칭·전사체 버전 문제가 대응) |
| 4 | 사용자 과신뢰·자동화 편향 | **제품 병용 시 의사결정 정확도**, 오류 포함 출력에 대한 사용자 검출률·수용률 | **미측정 (최대 공백)** |
| 5 | 데이터 편향 | 하위그룹 분석 | 코호트 5개 암종, CIViC 커버리지 편중 기술됨 |
| 6 | 장기 대화 맥락 누락 | 핵심 정보 보존율, 컨텍스트 초과 시 누락률 | 단발 호출이라 해당 적음 |
| 7 | 출력 비결정성 | **동일 입력 반복 실행 시 출력 일관성**(의미 유사도·일치율), 노이즈·데이터 증강 스트레스 시험 | Mode B 결정론, Mode A self-consistency 투표 |

위해요인 1의 위험통제로 문서가 **RAG를 명시**한다. "공인된 최신 임상 정보나 검증된 DB를 참조하여 결과를 생성하도록 설계"하라는 것이 곧 VeriVar의 citation-grounded retrieval이고, 검증 지표로 든 "근거 없는 주장 발생 비율"은 VeriVar의 hallucinated-citation rate와 같은 것을 잰다. 원고에서 **지표 선택의 외부 근거**로 인용할 수 있다.

4번(과신뢰)에는 각주가 붙어 있다. 단순 사용자 부주의가 아니라 1~3번 오류를 증폭하는 **기여인자(2차 위해요인)**로 규정하고, 위험통제로 human-in-the-loop 강제와 "출력을 확정이 아닌 검토 대상으로 제시"를 든다. VeriVar가 "expert-verifiable draft"를 목적으로 내세우면서 사람이 개입한 뒤의 정확도를 재지 않은 것은 여기에 정면으로 걸린다.

### 그 밖에 확인한 것

- 의료기기 해당 여부는 「디지털의료제품법」 제2조와 시행규칙 제11조(제외 대상)로 해석한다. 정의에 들어가도 제외 대상이면 요구사항을 강제하지 않는다.

### Ⅲ-4 중요한 변경 인·허가 대상 — 표8 직접 집계 (2026-08-07, 원문 p.29~31)

**해설글과 어긋나는 대목 두 가지.**
1. 해설글은 "모든 경미 변경에 핵심 임상성능 확인 조건이 붙는다"고 요약했지만, 원문에서 이 단서는 **경미 8건 중 3건(연번 1, 7, 8)에만** 달려 있다.
2. 근거 배분은 ① 세 건(1·7·8), ② 두 건(2·6), ③ 두 건(3·9), ④ 한 건(4), ⑤ 한 건(5)이다. 각주 7)은 사례마다 근거 하나만 제시했을 뿐 다른 근거에도 해당하는지 모두 검토해야 한다고 밝힌다.

**VeriVar에 직접 걸리는 것.**
- **연번 6이 멀티에이전트를 명시한다.** 단일 패스 추론에서 기능 분해·역할 분담·교차검증 구조로 바꾸는 것을 ②(분석 대상·방법의 변경)에 해당하는 **중요한 변경**으로 본다. "가이드라인이 멀티에이전트를 아직 상정하지 않았다"는 앞선 정리는 정확하지 않다. 자율 진단·처방까지는 다루지 않지만, 멀티에이전트 전환 자체는 변경관리에 이미 들어와 있다.
- **연번 7이 VeriVar의 self-consistency 투표와 맞물린다.** Temperature·Top-P가 사실성에 영향을 준다는 근거가 명시되어 있어, 파라미터를 기록·고정해야 할 이유가 규제 문서에 있다. Provenance 확장의 근거가 된다.
- **연번 1의 단서가 골든 세트 회귀 테스트의 근거다.** 모델을 갈아끼우고 경미로 넘어가려면 핵심 성능이 허가 범위 안임을 확인해야 하므로, 성능 동등성을 반복 확인하는 장치가 필요하다.

## 2. From Conversation to Chart (UC Irvine, medRxiv 2026-01-13)

- Guo Y, Hu D, Zhou Y, Lyu T, Sutari S, Tam S, Chow E, Perret D, Pandita D, Zheng K. UC Irvine. doi:10.64898/2026.01.05.26343471 (v2, CC-BY 4.0, 동료심사 전)
- 설계: 대형 학술의료기관 외래에서 두 벤더의 ambient AI 초안과 최종 서명본을 Myers diff로 비교한 후향 연구. 노트 23,760건(Vendor A 12,439 / B 11,321), 섹션 48,155개.
- 결과: **84.4%가 서명 전에 수정되었다.** 무수정 서명은 15.6%. 섹션별 무수정률이 갈리는데, **A&P가 가장 낮고(Vendor A 8.7%, B 19.2%)** Results가 가장 높다(72.5%, 62.0%). 변이의 주된 출처는 진료과가 아니라 **개별 임상의의 습관**이었다(ICC 0.54, 0.43). 24시간 넘겨 서명한 노트는 수정 강도가 낮았다.
- VeriVar에 주는 의미: 가이드라인이 A&P 생성을 규제 대상으로 보는 판단이 실제 편집 행동과 맞물린다. 임상의가 가장 많이 고치는 부분이 곧 규제가 짚은 부분이다.
- 더 중요한 것은 **연구 설계 자체가 VeriVar의 공백(위해요인 4)을 메우는 방법을 보여준다**는 점이다. 사람이 초안을 어떻게 고치는지를 diff로 재는 접근은, VeriVar의 adjudication worksheet를 reader study로 승격할 때 그대로 쓸 수 있다. 해석 라벨과 근거 인용이 전문가 손에서 어떻게 바뀌는지를 같은 방식으로 측정하면 된다.

## 3. Abridge Linked Evidence

- 생성된 의무기록의 문장을 원본 대화 구간으로 되짚어 확인하게 하는 기능이다. 상용 제품이 **문장 단위 근거 추적**을 이미 제품 기능으로 내놓았다는 사례.
- VeriVar의 faithfulness contract(검색된 식별자만 인용)와 목적이 같다. 관련 연구 문단에서 "산업계도 같은 방향으로 움직인다"는 근거로 쓸 수 있다.

## 4~7. 최윤섭 블로그 4편 (배경 문헌)

- **2023-08-04**: 범용 LLM은 사용 목적을 하나로 정의할 수 없고, 입출력 조합이 사실상 무한이며 환각 때문에 정확도를 정량화하기 어렵다는 문제 제기. 규제 난제의 출발점.
- **2024-10-03**: 생성형 의료 AI를 '새로운 지적 존재'로 보고 인간 의사 양성 체계(임상 교육, 면허 시험, 감독 훈련, 주기적 재시험, 성능 공개)를 본뜨자는 제안. 도발적이지만 VeriVar 원고에는 넣지 않는다.
- **2024-12-30**: FDA 디지털헬스자문위원회(2024-11) 발제문 해설. FDA도 사용 목적 특정의 어려움, 외부 파운데이션 모델의 불투명성, 환각의 불가피성, 출시 후 모델 변화 모니터링을 과제로 꼽았다. **식약처 안내서가 미해결로 남긴 외부 모델 드리프트를 FDA도 같은 문제로 본다**는 점이 확인된다.
- **2026-07-25**: 'AI 기본 의료 전략'(2026-07-22 관계부처 합동). 의료AI를 산업 육성이 아니라 의료 인프라로 놓고 국가가 지불자 역할을 맡는다는 내용. ambient scribe가 거의 모든 전략에 등장한다. VeriVar와는 거리가 있어 참고만 한다.
