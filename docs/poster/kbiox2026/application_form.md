## 초록 * (499자, 공백 포함)

```
체세포 변이 해석은 표적 치료 여부를 좌우하므로, 근거 인용을 지어내는 대규모 언어모델(LLM)은 판정이 맞더라도 임상에서 쓸 수 없다. 본 연구는 ClinGen/CGC/VICC 발암성과 AMP/ASCO/CAP 임상 등급 두 표준으로 변이를 분류하되, 검색된 근거의 식별자만 인용하고 변이별 근거가 없으면 기권하도록 강제하였다. TCGA 56개 변이와 전문가 판정 외부 기준 70개에서 평가하였고, 코퍼스 시간 분할과 자기근거 제거로 누수를 통제하였다. 검색을 붙이면 식별자 인용 86건 중 근거 밖은 0건이었으나, 검색이 없으면 56개 변이 중 19개가 조작되거나 잘못 귀속된 식별자를 인용하였다(McNemar p<0.001). 3분류 정확도는 0.600 대 0.586으로 차이가 없었다. 규칙 갈래는 발암성 과대 판정이 없었고(특이도 1.000) 정확도는 0.657이었다. 검색 정초는 정확도를 높이지 않으나 해석을 감사 가능하게 만든다. 코드와 데이터는 공개하였고 연구 목적에 한정한다.
```
